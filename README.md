# 📰 News API React App

A React-based News Application that fetches and displays the latest news using an external News API.

This project was created to practice and demonstrate important **React fundamentals**, including **Components, State Management, Effects, and API fetching**.

## 🌐 Live Demo

**[View Live Website](https://news-api-flax-theta.vercel.app/)**

## 🚀 Features

* Fetches news articles using an external News API
* Displays news dynamically using React components
* Handles application data using React State
* Uses React Effects for API-related operations
* Responsive and user-friendly interface
* Dynamic rendering of news articles
* API data handling and error management

## ⚛️ React Concepts Used

### 1. Components

The application is divided into reusable React components to keep the code organized, maintainable, and easy to understand.

### 2. State

React `useState` is used to manage dynamic data such as fetched news articles and application states.

### 3. Effects

React `useEffect` is used to perform side effects such as fetching news data when the application loads or when required dependencies change.

### 4. Fetch API

The JavaScript **Fetch API** is used to make HTTP requests to the News API and retrieve news data.

The fetched data is then processed and displayed dynamically through React components.
